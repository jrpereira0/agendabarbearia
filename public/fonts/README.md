# Fontes da marca

Arquivos em `public/fonts/`. Enquanto não estiverem aí, o site usa Outfit como reserva.

## Aeonik (corpo / formulários)

```
public/fonts/aeonik/
  Aeonik-Regular.woff
```

## Neue Montreal (títulos)

```
public/fonts/neue-montreal/
  NeueMontreal-Regular.woff
  NeueMontreal-Medium.woff
  NeueMontreal-Bold.woff
```

O CSS em `src/styles/brand-fonts.css` aponta só para esses `.woff`.
Se no futuro tiver `.woff2`, dá para acrescentar lá.

Depois de colar os arquivos, recarregue com `Ctrl+Shift+R`.
